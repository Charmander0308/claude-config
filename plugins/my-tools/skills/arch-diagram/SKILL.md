# 아키텍처 구조도 양식

`example.html`이 기준 결과물이고 `example.py`가 그것을 만든 스크립트다. 새 그림은 `example.py`를 복사해 내용(dict)과 좌표(`build()`)만 바꾼다. CSS는 `head.html`을 그대로 쓴다.

```sh
cp ~/.claude/skills/arch-diagram/example.py gen.py   # 작업 폴더에 복사 후 수정
python3 gen.py "$(TZ=Asia/Seoul date '+%Y-%m-%d %H:%M KST')" out.html
```
복사한 스크립트는 `head.html`을 자기 폴더에서 읽으므로, 함께 복사하거나 `HEAD` 경로를 스킬 폴더로 바꾼다.

## 배치
- 왼쪽 → 오른쪽으로 흐른다. 왼쪽 열 = 소스·빌드(레포, CI), 가운데 큰 구역 = 핵심 서버, 오른쪽 = 대상 클러스터·외부 서비스, 맨 아래 = 사람이 하는 단계.
- 서버·클러스터는 큰 구역(`.vm`/`.cl`, 굵은 테두리) 안에 상자를 둔다. 서버 안의 하위 시스템은 점선 묶음(`.group`)과 제목.
- viewBox 약 1290×745, `min-width: 980px`로 가로 스크롤 허용.

## 요소
- 상자(`box`): 첫 줄 굵은 제목(`t`), 가운데 줄은 평문, 마지막 줄은 회색 보조(`m`). 한 상자 2~5줄, 줄마다 몇 단어.
- 알약(`.pill`): 기록·상태 한 줄(예: 배포 기록). 실패 기록은 주황 점선 알약(`.pill.w`).
- 칩(`chip`): "임시", "설치 전" 같은 짧은 꼬리표.
- 번호 태그: 각 상자·구역 왼쪽 위 모서리에 파란 원 + 숫자, 읽는 순서대로 1부터. 번호의 설명은 페이지가 아니라 답변에 쓴다.

## 선
- 회색 실선 = 자동으로 동작, 회색 점선 = 사람이 함(또는 예정), 파란 굵은 선 = 강조할 주 흐름, 주황 점선 = 실패 시.
- 선 옆 라벨은 11px 짧은 말("성공", "받아감", "한 대씩 교체"). 강조 흐름 라벨은 파란색(`sa`), 실패는 주황(`sw`).
- 페이지 아래 범례에는 실제로 쓴 선 종류만 넣는다.

## 페이지
- 위: `h1` 제목, 그 아래 회색 한 줄 `YYYY-MM-DD HH:MM KST 기준`. 고칠 때마다 시각을 새로 넣는다.
- `svg`에 그림 전체를 한 문장씩 요약한 `aria-label`.
- 색은 CSS 변수만 쓴다(라이트·다크 자동). SVG 안에 색을 직접 쓰지 않는다. 글꼴은 IBM Plex Sans KR.

## 내용 규칙
- 끝난 구조만 그린다. "이전 중", "확인 대기" 같은 진행 상태는 넣지 않고 답변으로 말한다.
- 그림 아래 설명 문단(figcaption)을 넣지 않는다. 그림과 범례로 끝낸다.
- 두 가지 수준으로 나눌 수 있다. [공유용] = 역할을 쉬운 말로(IP·경로 최소). [개발용] = 호스트명·경로·유닛·설정값까지. 같은 `build()`에 dict만 바꿔 쓴다.
- 구조가 바뀌면 묻지 않고 그림을 갱신하고, 무엇이 바뀌었는지 답변에 적는다.

## 점검
- 글자 폭 어림: 12px 한글 한 글자 약 12px, 영문·숫자 약 7px. 상자 폭을 넘거나 선·태그와 겹치지 않는지 좌표로 확인한다.
- 선은 상자를 가로지르지 않게 꺾는다(`L('x1,y1 x2,y1 x2,y2 ...')`).
- 게시는 claude.ai 아티팩트(HTML 파일로 publish). 이미 게시된 그림은 같은 아티팩트에 새 버전으로 올린다.

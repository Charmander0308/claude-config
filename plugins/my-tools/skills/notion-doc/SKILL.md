# 노션 정리 문서 양식

## 넣을 곳
- Claude·Claude Code 관련 → "Claude" DB
- Claude 전용이 아닌 AI 툴 → "AI 도구" DB
- 일반 프로그램 → "유용한 소프트웨어" DB
- AI 개념·강의 → "AI Study" DB
- 위치를 따로 말하면 그곳에 둔다. DB는 `notion-search`로 찾는다.

## 쓰기 전
- 대상 DB를 fetch해 열 이름과 선택지를 확인한다. 평가 열 이름은 DB마다 다르다(추천도/중요도).
- 내용은 공식 README·문서·릴리스를 웹에서 확인해 쓴다. 기억으로 쓰지 않는다.
- 버전·별 개수 같은 수치는 조회한 날짜를 붙인다. 제작자가 주장하는 수치는 "제작자 측정"이라고 적는다.

## 제목·속성
- 제목: `이름 — 무엇인지 한 줄`. 아이콘은 내용에 맞는 이모지 하나.
- 분류: DB에 이미 있는 선택지에서 고른다. 맞는 게 없으면 새로 만들지 말고 묻는다.
- 평가 열(추천도/중요도): "1"을 넣는다. 올리는 것은 사용자가 한다.
- 작성일·수정일·작성자는 자동 열이라 넣지 않는다.

## 본문 순서
1. 첫 줄: `<b>설치:</b>` 공식 다운로드·스토어·설치 명령·GitHub 링크를 ` · `로 잇는다. 설치할 게 없으면(API·웹 서비스·개념) 가장 가까운 시작 링크를 넣는다. 이 줄은 빼지 않는다.
2. 회색 💡 callout(`color="gray_bg"`): 무엇인지, 어떻게 쓰는지, 라이선스·요금, 큰 주의점을 3~6문장으로 요약한다. 끝에 `확인일: <date start="YYYY-MM-DD" />`.
3. `## 한눈에 보기`: `항목 | 내용` 2열 표. 칸에는 값만 넣는다.
4. `## 기능별 정리`(내용에 맞게 제목 조정) 아래 `### 항목`마다 `- <b>라벨:</b> 내용` 글머리표.
5. `## 주의할 점`: 같은 `<b>라벨:</b>` 형식. 보안 사고, 함정 설정, 유료 범위 등.
6. `## 원본 글과 달라진 점`: SNS 글처럼 사용자가 준 원본이 있고 현재 공식 문서와 다를 때만 넣는다.
7. `## 출처`: 링크마다 무엇인지와 조회 방법·날짜를 짧게 붙인다.

## 문체
- "~다" 평서체. 전문 용어는 처음 나올 때 쉬운 말로 풀어 쓴다.
- 저작권 있는 글은 통째로 옮기거나 전부 번역하지 않는다. 요약하고 원문 링크를 단다.

## 끝나면
- 만든 페이지를 다시 fetch해 서식과 속성이 들어갔는지 확인한다.
- 답변에는 링크와 한 줄 요약만 쓴다.
- 기존 문서의 속성은 요청 없이 바꾸지 않는다. 바꾸면 그 문서의 마지막 수정일이 오늘로 바뀐다.
